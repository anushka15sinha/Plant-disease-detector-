# LeafScan — Plant Disease Detector

An AI-powered plant leaf disease detection app built with **Streamlit** + **PyTorch EfficientNet-B0**, supporting **15 disease conditions** across **3 crop species** (Bell Pepper, Potato, Tomato) using the PlantVillage dataset.

---

## Quick Start locally

### 1. Install dependencies (only once)
```bash
cd plant-disease-detector
pip install -r requirements.txt
```

### 2. Train the model on your dataset
```bash
python train.py
```
Place your `PlantVillage/` folder in the same directory first. Training takes ~10–20 min on CPU, ~3–5 min on GPU. Saves `plant_disease_model.pth` when done.

### 3. Run the app
```bash
python -m streamlit run app.py
```

Opens at `http://localhost:8501`

##  How It Works

| Component | Detail |
|---|---|
| **Model** | EfficientNet-B0 (ImageNet pretrained, fine-tuned on PlantVillage) |
| **Dataset** | PlantVillage — emmarex version (20,638 images, 15 classes) |
| **Input** | Any JPG/PNG/WEBP leaf image |
| **Output** | Top-5 predictions with confidence scores + disease info |
| **Classes** | 15 disease/healthy states across 3 plant species |
